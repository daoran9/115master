# 播放器详情图片现场复核

Status: ready-for-human

## 现象

播放器详情区曾出现演员头像和剧照加载失败。失败节点仍占据固定尺寸，导致大块留白和布局断层。

## 当前状态

- `2.0.0-beta.74` 已修复并通过自动化。
- JavDB 演员头像已补齐当前详情页 Referer。
- 头像和剧照统一走 GM 图片加载器。
- 剧照优先缩略图，失败后退出网格。
- 演员头像失败时显示受控占位。

## 人工验收

1. 在真实播放器打开 `NMSL-045`。
2. 在普通模式检查演员头像和剧照。
3. 切换剧院模式，再检查头像、剧照和滚动范围。
4. 确认单张图片失败时不撑高详情区，不打断标题、演员和番号信息。

## 边界

页面上的“下载该视频”“从该页面下载视频”浮层疑似来自浏览器下载扩展，不归因给 115Master。
